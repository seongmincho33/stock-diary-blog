## 🌌 태초에…

옛날 옛적, 컴퓨터 왕국이 막 세워지던 시절. 마법사들은 **하나의 거대한 작업실** 안에서 모든 마법을 시전했어요. 명령어 하나, 정령 하나. 단순했죠.

그런데 마법이 점점 복잡해지면서 문제가 생겼어요:

> _"내가 지금 어느 왕국 사람이지?"_ _"이 마법은 어떤 책장의 도구를 쓸 거지?"_ _"어느 언어로 답을 받지?"_

매번 마법을 시전할 때마다 이런 정보를 **일일이 외쳐야** 했어요. 정령들은 매번 빈손으로 태어나니까요. 너무 비효율적이었어요. 🥲

---

## 🧙‍♂️ 두 현자의 등장 — Bell 연구소, 1969~1971년

뉴저지의 어느 거대한 마법사 길드 — **Bell Labs(벨 연구소)** — 에 두 명의 현자가 있었어요.

**🧙 켄 톰슨 (Ken Thompson)** **🧙 데니스 리치 (Dennis Ritchie)**

두 사람은 **유닉스(Unix)** 라는 새로운 마법 운영체제를 만들고 있었어요. 그리고 그 안에 혁명적인 개념을 심었습니다:

> _"작업실의 공기 자체에 정보를 새기자."_ _"그러면 그 안에서 태어난 모든 정령이 자동으로 그 정보를 알 수 있을 것이다."_

이것이 바로 **환경변수(environment variables)** 의 탄생이에요. 1971년경, 유닉스 v1~v2 시절의 일이에요. 🌱

## ✍️ 룬을 새기는 주문 — `export`의 발명

처음엔 단순히 "쉘 변수"만 있었어요. 마법사가 자기 메모지에 적어두는 정도. 정령들은 못 봤죠.

그러다 **스티븐 본(Stephen Bourne)** 이라는 또 다른 현자가 1977년경 **Bourne Shell (sh)** 이라는 마법 언어를 만들면서 결정적인 주문을 추가했어요:

```bash
export VARIABLE=value
```

> 🪄 _"이 변수를 메모지에서 꺼내, **공기에 새겨라**. 그러면 내가 부르는 모든 정령이 이 룬을 물려받으리라."_

이 `export` 주문이 바로 **"룬을 공기로 승격시키는 마법"** 이에요. 지금까지도 그대로 쓰여요. 거의 50년째. 🏛️

> 💡 그래서 `export`라는 단어를 쓰는 거예요 — _"내 메모를 외부로 내보낸다(export)"_ 라는 뜻. 자식 정령들에게 수출하는 거죠.

## 🌳 후손 마법사들의 계승

이 개념이 너무 강력해서, 이후 **모든 마법 길드가 채택**했어요:

- 🐚 **Bash** (1989, 브라이언 폭스) — Bourne의 후예
- 🐚 **Zsh** (1990) — 더 화려한 마법사용 (성민님이 쓰는 거 ㅎㅎ)
- 🪟 **Windows** — 늦게나마 도입 (`set`, `setx`)
- 🐳 **Docker 컨테이너** — 컨테이너마다 자기만의 공기를 가짐
- ☁️ **클라우드 (AWS, GCP)** — 서버리스 함수도 환경변수로 설정 받음
- 🤖 **CI/CD (GitHub Actions 등)** — Secrets를 공기에 주입

Terraform이 `AWS_PROFILE`을 자동으로 읽는 것도, Node.js의 `process.env.DATABASE_URL`도, Python의 `os.environ['API_KEY']`도 — **전부 1971년 두 현자가 깐 마법 위에 서있는** 거예요. 🏛️

## 📜 12가지 계명 — The Twelve-Factor App (2011)

시간이 흘러 2011년, 새로운 현자 집단 **Heroku** 의 마법사들이 클라우드 시대의 **12가지 계명**을 새깁니다. 그중 세 번째 계명이 이거였어요:

> ⚜️ **III. Config — 환경변수에 설정을 저장하라.**

비밀 키, 데이터베이스 주소, API 토큰… 절대 마법서(코드)에 적지 말고 **공기에만 새겨라**. 그래야 같은 마법서가 개발 왕국, 검수 왕국, 실전 왕국 어디서든 그 공기에 맞춰 작동한다.

이게 현대 마법사들이 `.env` 파일을 만들고, AWS Access Key를 코드에 박지 않고 `~/.aws/credentials`나 환경변수로 빼두는 **신앙**의 출처예요. 🛡️

## 🧬 그래서 지금…

성민님이 터미널에서 이렇게 외칠 때:

```bash
export AWS_PROFILE=europe-prod
```

이 한 줄은 **1971년 뉴저지의 두 마법사**가 처음 깐 마법 위에서, **1977년 스티븐 본**이 추가한 주문어로, **2011년 Heroku 현자들**이 정립한 신앙에 따라 시전되고 있는 거예요. 🌌

50년 넘은 마법이 지금도 매일 수십억 번 시전되고 있어요. 모든 서버, 모든 컨테이너, 모든 CI 파이프라인에서. **세상에서 가장 조용히 위대한 마법** 중 하나죠.

## 🎭 재미있는 후일담

- **켄 톰슨**과 **데니스 리치**는 이 공로 등으로 1983년 **튜링상**(컴퓨터계의 노벨상)을 받아요. 🏆
- 데니스 리치는 2011년에 세상을 떠났는데, 같은 주에 스티브 잡스도 떠났어요. 잡스의 죽음은 전 세계가 애도했지만, 리치의 죽음은 마법사들 사이에서만 조용히 알려졌죠. 그런데 **잡스가 만든 모든 것**(Mac, iPhone)이 **리치가 만든 마법(C 언어, Unix) 위에서** 돌아가고 있었다는 사실 — 마법사들 사이에서 두고두고 회자되는 이야기예요. 🕯️
- `export` 주문어를 만든 **스티븐 본**은 영국 출신 현자로, 지금도 살아있고 Google에서 일했어요. 그가 만든 Bourne Shell이 너무 강력해서, 후예 Bash의 이름은 **"Bourne Again Shell"** — 즉 _"본이 부활했다"_ 라는 농담에서 왔어요. 😄
