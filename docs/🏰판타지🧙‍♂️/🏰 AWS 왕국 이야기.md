## 🏰 AWS 왕국 이야기

당신은 방금 **AWS 왕국**의 시민증을 발급받았어요. 이게 바로 **IAM 계정 (ID + PW)**.

이 시민증으로는 왕국의 **웹 포털 (콘솔)** — 그러니까 거대한 마법사 길드의 정문 — 을 통해 들어갈 수 있어요. 문지기한테 ID/PW 보여주면 "어서오세요~" 하고 들여보내줌. 안에서 마우스로 클릭하면서 EC2 서버 만들고, S3 창고 만들고 다 할 수 있어요.

### 그런데 문제가 생겼어요 🤔

당신은 게을러서(?) 매번 정문까지 걸어가기 싫어요. 자기 방(로컬 터미널)에서 **마법 주문(`terraform apply`)** 한 번으로 왕국에 성을 짓고 싶음.

근데 마법은 어떻게 왕국에 닿죠? 당신 방에서 외친 주문이 진짜 당신이 쓴 건지 왕국이 어떻게 알아요?

### 그래서 필요한 게... 🔑 마법 인장

**Access Key ID** = 마법사의 **인장 이름** (공개되어도 됨, 누구 인장인지만 알려줌) **Secret Access Key** = 인장을 찍을 때 쓰는 **비밀 마력** (절대 노출 X)

이 둘을 합치면 **원격 마법 시전권**이에요. 정문 안 거치고도 "나 ○○○이고, 이 마력으로 증명함. 성 지어줘" 하면 왕국이 "오케이~" 하고 일을 처리해줘요.

> ID/PW는 **사람이 직접 들어갈 때** 쓰는 거고 Access Key는 **코드/터미널이 대신 들어갈 때** 쓰는 거예요.

둘은 같은 시민의 다른 출입 수단이에요.

## 🗝️ 그래서 어떻게 받냐?

방법 1: **본인이 직접 발급** (보통 권한 있으면 가능)

1. AWS 콘솔에 ID/PW로 로그인
2. 우측 상단 본인 이름 클릭 → **Security credentials** (보안 자격 증명)
3. **Access keys** 섹션 → **Create access key** 버튼
4. "Command Line Interface (CLI)" 선택
5. 발급되면 **Access Key ID**랑 **Secret Access Key** 두 개가 화면에 뜸

⚠️ **Secret Access Key는 이때 딱 한 번만 보여줘요.** 창 닫으면 영영 못 봄. `.csv`로 다운받아두거나 비밀번호 매니저에 바로 저장하세요.

방법 2: **권한이 없어서 버튼이 안 보이거나 막혀있다면**

회사 AWS 관리자(iMAX 쪽이면 그쪽 담당자)한테 "CLI 쓰려고 하는데 access key 발급 권한 좀요" 또는 "발급해서 전달 부탁드려요" 하면 돼요. 회사 정책상 본인 발급 못 하게 막아둔 곳도 많아요.

## ⚠️ 중요한 보안 룰

- Secret Access Key는 **카톡, Slack, Git, 메모장 공유** 절대 금지. 유출되면 누가 당신 이름으로 EC2 100대 띄우고 비트코인 채굴하고 도망감 (실화임 😇)
- 발급받으면 `~/.aws/credentials`에만 저장하고, 이 폴더는 `.gitignore`에 꼭 넣기
- 안 쓰는 키는 콘솔에서 **Deactivate / Delete**로 폐기
