스프링, 클라우드와 만나다

Welcome to the cloud, Spring

마이크로서비스가 무엇이고 왜 Spring Boot/Spring Cloud로 만드는지를 소개하는 장입니다. 코드는 "Spring Boot로 REST 엔드포인트 하나 만드는 게 이만큼 간단하다"를 보여주는 파일 한 개짜리 맛보기뿐입니다.

  • Spring Boot 2.2.2
  • Java 11
  • spring-boot-starter-web

이 장의 목표

  • 모놀리스 vs 마이크로서비스, 클라우드 배포 모델(IaaS/PaaS/SaaS/FaaS/CaaS) 개념 정리
  • Spring Boot가 마이크로서비스에 적합한 이유 — 최소 설정으로 독립 실행 가능한 JAR
  • 책 전체에서 다룰 패턴(핵심 개발·라우팅·클라이언트 회복성·보안·로깅/추적·빌드/배포)을 지도처럼 훑기

코드 구성

chapter1/
└── simple-application/

application.properties는 비어 있고, DB·Docker·Spring Cloud는 전혀 없습니다.

핵심 코드

Application.java 한 클래스가 부트스트랩 클래스이자 컨트롤러입니다. 같은 파일 아래에 요청 DTO HelloRequest가 패키지-프라이빗 클래스로 들어 있습니다.

@SpringBootApplication
@RestController
@RequestMapping(value="hello")
public class Application {

    @GetMapping(value="/{firstName}")
    public String helloGET(@PathVariable("firstName") String firstName,
                           @RequestParam("lastName") String lastName) {
        return String.format("{\"message\":\"Hello %s %s\"}", firstName, lastName);
    }

    @PostMapping
    public String helloPOST(@RequestBody HelloRequest request) {
        return String.format("{\"message\":\"Hello %s %s\"}",
                request.getFirstName(), request.getLastName());
    }
}
메서드경로입력응답
GET/hello/{firstName}?lastName=…경로 변수 + 쿼리{"message":"Hello 길동 홍"}
POST/helloJSON {"firstName":"…","lastName":"…"}동일

응답 JSON을 직접 문자열로 조립하는데, 3장부터는 객체를 반환해 Jackson이 직렬화하도록 바뀝니다.

실행

cd chapter1/simple-application
mvn spring-boot:run
#   또는 mvn install && java -jar target/SimpleApplication-0.0.1-SNAPSHOT.jar

curl "http://localhost:8080/hello/Illary?lastName=Huaylupo"
curl -X POST http://localhost:8080/hello -H 'Content-Type: application/json' \
     -d '{"firstName":"Illary","lastName":"Huaylupo"}'

메모

  • Spring Boot 2.2.2(다른 장은 2.2.3). Java 17 이상에서는 Spring Boot 2.2가 제대로 돌지 않으니 Java 11을 쓰세요.
  • 테스트는 contextLoads() 빈 테스트 하나. JUnit 5(vintage 엔진 제외).
  • Postman 컬렉션 "Chapter-1 GET Hello" 항목이 이 엔드포인트입니다.
