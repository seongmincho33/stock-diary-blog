공통 실행 방법

1~3장은 Maven만으로 실행하고, 4장부터는 Docker 이미지를 빌드해서 docker-compose로 올립니다.

# 사전 준비: Java 11 + Maven + Docker Desktop
mvn --version            # Java version: 11.x 확인

# 1~3장: 단일 프로젝트
cd chapter3/licensing-service
mvn spring-boot:run

# 5장 이후: 멀티 모듈 + docker-compose
cd chapter7
./build-for-m1.sh        # Apple Silicon → mvn clean package + docker build (각 모듈)
#   또는 mvn clean package dockerfile:build   (Intel / spotify 플러그인이 동작할 때)
docker-compose -f docker/docker-compose.yml up

Apple Silicon 주의. 원본은 dockerfile-maven-plugin(Spotify)으로 이미지를 만드는데 arm64에서 깨지는 경우가 있어, 포크 작성자가 각 장에 build-for-m1.sh를 추가했습니다. 내용은 mvn clean package 후 모듈마다 docker build --build-arg JAR_FILE=...을 수동 실행하는 것입니다. Kafka·Keycloak 등 일부 이미지는 amd64/arm64 모두 지원하는 것으로 교체되어 있습니다.

API 테스트는 저장소 루트의 Spring_Microservices_in_Action_2nd.postman_collection.json(1~11장)과 chapter6/chapter6.postman_collection.json을 Postman에 가져오면 됩니다.
