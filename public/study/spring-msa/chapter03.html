스프링 부트로 마이크로서비스 구축하기

Building microservices with Spring Boot

licensing-service에 REST CRUD 컨트롤러, 서비스 계층, 모델을 채워 넣습니다. 아직 DB는 없고 더미 데이터를 돌려주지만, HATEOAS 링크·국제화(i18n)·Actuator 같은 "프로덕션 준비" 요소를 함께 다룹니다.

  • Spring Boot 2.2.3
  • spring-boot-starter-hateoas
  • MessageSource i18n
  • Actuator

이 장의 목표

  • 컨트롤러 → 서비스 → 모델 3계층으로 마이크로서비스 작성
  • REST 설계: JSON, HTTP 동사, URL에 리소스 의미 담기(/v1/organization/{orgId}/license/{licenseId})
  • HATEOAS로 응답에 관련 링크(self / create / update / delete) 포함
  • 국제화 — Accept-Language 헤더에 따라 메시지 번들 선택
  • Actuator /actuator/health로 서비스 상태 노출

핵심 코드

LicenseController — 리소스 중심 URL

@RestController
@RequestMapping(value="v1/organization/{organizationId}/license")
public class LicenseController {

    @RequestMapping(value="/{licenseId}", method = RequestMethod.GET)
    public ResponseEntity<License> getLicense(@PathVariable String organizationId,
                                              @PathVariable String licenseId) {
        License license = licenseService.getLicense(licenseId, organizationId);
        license.add(
            linkTo(methodOn(LicenseController.class).getLicense(organizationId, license.getLicenseId())).withSelfRel(),
            linkTo(methodOn(LicenseController.class).createLicense(organizationId, license, null)).withRel("createLicense"),
            linkTo(methodOn(LicenseController.class).updateLicense(organizationId, license)).withRel("updateLicense"),
            linkTo(methodOn(LicenseController.class).deleteLicense(organizationId, license.getLicenseId())).withRel("deleteLicense"));
        return ResponseEntity.ok(license);
    }

    @PostMapping
    public ResponseEntity<String> createLicense(@PathVariable String organizationId, @RequestBody License request,
            @RequestHeader(value = "Accept-Language", required = false) Locale locale) { … }
    @PutMapping    public ResponseEntity<String> updateLicense(…) { … }
    @DeleteMapping(value="/{licenseId}") public ResponseEntity<String> deleteLicense(…) { … }
}

LicenseService — 아직 DB 없음

getLicense()는 new License()에 값을 채워 돌려주고, create/update/delete는 MessageSource로 만든 문자열 메시지를 반환합니다.

responseMessage = String.format(
    messages.getMessage("license.create.message", null, locale), license.toString());

국제화 설정 (LicenseServiceApplication)

@Bean public LocaleResolver localeResolver() {
    SessionLocaleResolver r = new SessionLocaleResolver();
    r.setDefaultLocale(Locale.US);        // Accept-Language 없으면 en
    return r;
}
@Bean public ResourceBundleMessageSource messageSource() {
    ResourceBundleMessageSource ms = new ResourceBundleMessageSource();
    ms.setUseCodeAsDefaultMessage(true);  // 키 못 찾으면 키 자체를 반환
    ms.setBasenames("messages");          // messages_{lang}.properties
    return ms;
}
