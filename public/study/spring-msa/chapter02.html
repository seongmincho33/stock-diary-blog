스프링 클라우드와 함께하는 마이크로서비스 세계 탐험

Exploring the microservices world with Spring Cloud

Spring Cloud 생태계(Config, Discovery, Gateway, Resilience4j, Stream, Sleuth 등)를 개관하고, 책 전체에서 키워 나갈 licensing-service의 뼈대를 Spring Initializr로 만드는 장입니다. 코드는 컨트롤러도 없는 빈 애플리케이션입니다.

  • Spring Boot 2.2.3
  • Java 11
  • starter-web
  • starter-actuator
  • Lombok

이 장의 목표

  • 마이크로서비스 설계 원칙 — 서비스 경계 나누기, "너무 작거나 너무 큰" 서비스의 징후
  • 아키텍트 / 개발자 / DevOps 세 역할의 관점에서 마이크로서비스 보기
  • 12 팩터 앱(코드베이스, 의존성, 구성, 백킹 서비스, 로그…) 원칙과 Spring Cloud가 어떻게 뒷받침하는지
  • Spring Initializr로 프로젝트 골격 만들기, 부트스트랩 클래스 이해

코드 구성

chapter2/
└── licensing-service/
    ├── pom.xml                              # web, actuator, lombok, test
    └── src/main/java/com/optimagrowth/license/
        └── LicenseServiceApplication.java   # @SpringBootApplication 뿐

이 장부터 패키지가 com.optimagrowth.license로 바뀌고, 이 디렉터리 구조가 12장까지 그대로 유지됩니다. README는 없습니다.

핵심 코드

@SpringBootApplication
public class LicenseServiceApplication {
    public static void main(String[] args) {
        SpringApplication.run(LicenseServiceApplication.class, args);
    }
}

@SpringBootApplication = @Configuration + @EnableAutoConfiguration + @ComponentScan. 엔드포인트는 없지만 actuator 덕분에 /actuator/health는 응답합니다.

실행

cd chapter2/licensing-service
mvn spring-boot:run
curl http://localhost:8080/actuator/health     # {"status":"UP"}

메모

  • 3장에서 컨트롤러·서비스·모델이 채워지므로, 2장은 "프로젝트를 만들었다"는 의미만 있습니다.
  • Lombok이 의존성에 있으니 IDE에 Lombok 플러그인을 설치해 두세요(3장부터 @Getter @Setter 사용).
