> *「ID/PW는 사람이 드나드는 문, Access Key는 주문이 드나드는 문」*

🗓️ 2026.08.22 (토) · 개발일지 2화 — AWS 왕국 표류기 ①: IAM 시민증과 마법 인장(Access Key)

석판 굽기는 잠시 미뤄야 했다. 공방장이 더 급한 의뢰를 들고 왔기 때문이다.

> "바다 건너 구름 위에 **AWS 왕국**이 있소. 이웃 **달빛 상단**이 그 왕국에 상점을 내려는데 손이 모자란다오. 시민증은 내가 미리 받아뒀으니, 가서 좀 도와주시오."

공방장이 내민 건 이름과 암호가 적힌 패 하나였다. 이게 **IAM 계정(ID + PW)** 이다.

## 등장인물

- **공방장** — 퀘스트를 주는 사람. 늘 "급하다"고 한다.
- **셸리** — 검은 창의 셸 정령. 이번 화에선 내 방(터미널)의 주인으로 등장.
- **테라** — 셸리가 부르면 나타나는 건축 정령(terraform). 설계도 한 장이면 성을 짓는다. 첫 등장.

## 시민증으로 할 수 있는 것

시민증이 있으면 왕국의 **정문(웹 콘솔)** 으로 들어갈 수 있다. 거대한 마법사 길드의 정문 같은 곳이다. 문지기한테 ID/PW를 보여주면 "어서 오세요" 하고 들여보내 준다. 안에서는 마우스로 클릭해 가며 **EC2 서버**도 만들고 **S3 창고**도 만들 수 있다. 다 된다.

## 그런데 문제가 생겼다

나는 게을러서(?) 매번 정문까지 걸어가기가 싫다. 셸리의 작업실(로컬 터미널)에 앉은 채로 **주문 한 번(`terraform apply`)** 으로 왕국에 성을 짓고 싶다. 테라를 부르면 되니까.

그런데 주문은 어떻게 왕국에 닿나? 내 방에서 외친 주문이 진짜 내가 쓴 건지, 왕국은 어떻게 아나? 시민증을 테라한테 쥐여 보낼 수도 없고.

## 그래서 필요한 게, 마법 인장

- **Access Key ID** = 마법사의 **인장 이름**. 공개돼도 된다. 누구 인장인지만 알려준다.
- **Secret Access Key** = 인장을 찍을 때 쓰는 **비밀 마력**. 절대 노출하면 안 된다.

이 둘을 합치면 **원격 마법 시전권**이다. 정문을 안 거치고도 "나 ○○○이고, 이 마력으로 증명함. 성 지어줘" 하면 왕국이 "오케이" 하고 일을 처리해 준다.

> ID/PW는 **사람이 직접 들어갈 때** 쓰는 것이고,
>
> Access Key는 **코드/터미널이 대신 들어갈 때** 쓰는 것이다.

같은 시민의 **다른 출입 수단**일 뿐이다. 원래 세계로 치면 은행 창구에서 쓰는 신분증과, HTS가 대신 쓰는 공동인증서의 관계다.

## 그래서 인장은 어떻게 받나

**방법 1: 본인이 직접 발급** (보통 권한이 있으면 가능)

1. AWS 콘솔에 ID/PW로 로그인
2. 우측 상단 본인 이름 클릭 → **Security credentials** (보안 자격 증명)
3. **Access keys** 섹션 → **Create access key** 버튼
4. "Command Line Interface (CLI)" 선택
5. 발급되면 **Access Key ID**와 **Secret Access Key** 두 개가 화면에 뜬다

**⚠️ Secret Access Key는 이때 딱 한 번만 보여준다.** 창을 닫으면 영영 못 본다. `.csv`로 내려받아 두거나 비밀번호 관리자에 바로 저장하자. 원래 세계에서 비밀번호 메모를 잃어버리고 공인인증서를 다시 발급받던 기억이 떠오른다면, 맞다, 그 감정이다.

**방법 2: 권한이 없어서 버튼이 안 보이거나 막혀 있다면**

상단의 AWS 관리자에게 "CLI 쓰려고 하는데 access key 발급 권한 좀 주세요" 또는 "발급해서 전달 부탁드려요" 하면 된다. 회사 정책상 본인 발급을 막아 둔 곳도 많다.

## 중요한 보안 룰

- Secret Access Key는 **카톡, Slack, Git, 메모장 공유** 절대 금지. 유출되면 누가 내 이름으로 EC2 100대를 띄워 비트코인을 채굴하고 도망간다. (실화다.) 그리고 그 코인은 내 계좌에 들어오지 않는다. 청구서만 들어온다.
- 발급받으면 `~/.aws/credentials`에만 저장한다. 프로젝트 안의 `.env` 같은 파일에 옮겨 적었다면 그 파일은 `.gitignore`에 꼭 넣는다.
- 안 쓰는 키는 콘솔에서 **Deactivate / Delete**로 폐기한다.

## 캐릭터 시트

```
이름: 단타마스터
직업: 이방인 견습 (Lv. 2)
현재 퀘스트: 달빛 상단의 AWS 왕국 진출 지원
현재 단계: 마법 인장 발급

획득한 지식:
- 📜 IAM 계정(ID/PW) = 시민증, 정문(콘솔)용
- 📜 Access Key ID = 인장 이름 (공개 OK)
- 📜 Secret Access Key = 비밀 마력 (한 번만 보여줌, 절대 노출 X)
- 📜 둘은 같은 시민의 다른 출입 수단

새로 배운 마법:
- 🪄 Security credentials → Create access key
```

### 오늘의 교훈

콘솔에 들어가서 Security credentials 메뉴를 먼저 보자. **Create access key 버튼이 살아 있으면 바로 발급**, 회색이거나 없으면 관리자 호출이다.
